# v0.30.0 — Push Notifications

**Date:** 2026-04-22
**Spec:** [32 — Push Notifications](../specs/32-push-notifications.md)

## Summary

Web Push notifications for session lifecycle events and admin-initiated check-in/out actions. Uses the Web Push API with VAPID authentication and a service worker.

## DB Changes

- **New table:** `push_subscriptions` — stores player push subscription endpoints (player_id, endpoint, p256dh, auth keys). Unique constraint on (player_id, endpoint). Cascades on player delete.
- **New index:** `idx_push_subs_player` on `push_subscriptions(player_id)`

## New Environment Variables

| Variable | Scope | Description |
|----------|-------|-------------|
| `VAPID_PUBLIC_KEY` | Server + browser | VAPID public key (base64url) |
| `VAPID_PRIVATE_KEY` | Server only | VAPID private key (base64url) |
| `VAPID_SUBJECT` | Server only | Contact URI for VAPID |

## New Dependencies

- `web-push` — server-side push message sending
- `@types/web-push` (dev) — TypeScript types

## Stale subscription cleanup

When a push send returns 410 Gone or 404, the subscription is automatically deleted from the database.
