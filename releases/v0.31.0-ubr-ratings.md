# v0.31.0 — UBR (Universal Badminton Rating)

**Date:** 2026-05-01

## Summary

Adds a complete player rating system based on modified Elo with Glicko-1 confidence tracking. Supports all three scoring modes (full, simple, whiteboard/tally). Ratings are cached in the database, computed incrementally on session finalization, and displayed in the leaderboard and player profile pages.

## DB Migration

- `ubr_ratings` — cached current ratings (player_id PK, rating, rating_deviation, match_count, tier)
- `ubr_history` — per-session audit trail (player_id + session_id unique, rating_before/after/change)
