# v0.17.12 — Auto-checkout on session close

## What changed
When an admin closes a session, all `session_players` rows with `checked_out_at = null` are bulk-updated to the current timestamp before the session status is set to `completed`.

## Files modified
| File | Change |
|---|---|
| `src/app/api/sessions/[id]/close/route.ts` | Added bulk checkout of remaining players before closing session |

## Notes
- No DB schema changes.
- The checkout happens unconditionally (no error is raised if no players are still present — it's a no-op).
- Proposed-match cleanup is intentionally skipped here; the session is closed so those records are moot.
