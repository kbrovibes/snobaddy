# v0.25.0 — Season Finals (God Mode gated)

## What's new

Season Finals infrastructure — Tasks 1–2 of Spec 27.

### Task 1: DB Migration
- New table: `finals_events` (UNIQUE on `season_id` — one per season)
- New table: `finals_participants`
- `sessions.session_type` (default `'regular'`)
- `sessions.finals_event_id` (nullable FK)
- `matches.match_type` (default `'regular'`)
- `matches.finals_group` (nullable)

### Task 2: Entry Point
- `POST /api/finals` — create Finals Event for the current season
- `GET /api/finals/[id]` — fetch event details
- `DELETE /api/finals/[id]` — delete draft event
- `/finals/[id]` page — 3-tab skeleton (Players / Groups / Sessions)
- Sessions list: pinned "Season Finals" section (God Mode only)

## Impact on existing features
None. All changes are additive. God Mode gate ensures zero visibility to other users.
