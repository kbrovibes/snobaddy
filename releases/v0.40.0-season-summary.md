# v0.40.0 — Season Summary Page + Season Transition UX

**Released:** 2026-05-24

## New: Season Summary Page

**Route:** `(app)/seasons/[id]/page.tsx`

A read-only season retrospective page accessible to all authenticated users. Linked via "View Season Summary →" on every SeasonCard in the admin Seasons tab.

**Sections:**
1. Back link (← Sessions)
2. Season name + status badge + date range
3. Stat tiles: Players, Matches, Days of Play (always shown, 0 values when empty)
4. Season Leaderboard with award cards — rendered via the existing `LeaderboardData` Suspense component (only shown when `daysOfPlay > 0`)
5. Session list — read-only, no admin controls. Pending sessions in a completed season are labelled "Not Held" instead of "Upcoming"

**New DB function:** `getSeasonById(id)` in `src/lib/db/seasons.ts`

## New: "Starting Soon" Banner

`src/app/(app)/page.tsx`

When the active season has `daysOfPlay === 0` (no completed sessions) and sessions exist, a full-width card appears between the stat tiles and the session list. Shows the season name, date range, and first upcoming session date.

## Fix: FinalsSection Collapsible

`src/components/finals/FinalsSection.tsx`

Wrapped entire section in `<details open={!!event}>`. Collapsed by default when no finals event exists for the current season; open by default when a finals event is present. No client JS required — native HTML `<details>` handles toggle.

## Fix: SeasonCard Finals Status Label

`src/components/SeasonCard.tsx`

Added `FINALS_STATUS_LABELS` mapping. Raw DB values like `"sessions_created"` now display as `"Sessions Set"`, `"breakdown_generated"` as `"Groups Ready"`, etc.

Also added `View Season Summary →` link to each SeasonCard's expanded section.
