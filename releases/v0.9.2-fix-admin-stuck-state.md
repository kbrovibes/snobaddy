# Release v0.9.2 — Fix Match Admin Stuck State

## Overview
This patch fix addresses a UI bug where the match administration controls (edit/delete) would get stuck in a "Saving..." or "Deleting..." state even after the database operation was completed.

## Changes

### 1. Reset Admin Control State
- **Component:** `src/components/MatchAdminControls.tsx`
- **Before:** After calling the `fetch` API and `router.refresh()`, the component's `loading` and `mode` states remained unchanged. This caused the "Saving..." label to persist and the buttons to remain disabled.
- **After:** Explicitly added `setLoading(false)` and `setMode("idle")` to both `handleSave` and `handleDelete` handlers. This returns the UI to its initial "Edit scores / Delete" state immediately after the operation finishes.

## Technical Notes
- `router.refresh()` triggers a server-side re-render, but since this is a client component, its internal state is preserved across that refresh. Manual state reset is required to transition back to the "idle" mode.
- Added similar state management to the delete operation for robustness, ensuring that if for some reason the component isn't unmounted immediately, it won't be stuck in a disabled state.
