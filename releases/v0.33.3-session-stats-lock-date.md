# v0.33.3 — Session Stats Lock-In Date

## Summary
Admins can set a per-session stats lock-in date. After that date the session's data is excluded from leaderboard stats and match counts.

## DB Migration
`supabase/migrations/20260512_session_stats_lock_date.sql`
```sql
ALTER TABLE sessions ADD COLUMN IF NOT EXISTS stats_lock_date DATE NULL;
```
Run this in the Supabase SQL editor before deploying.

## Behavior
- `stats_lock_date` is nullable. Null means no lock (always counts).
- A session is **locked** when `stats_lock_date IS NOT NULL AND stats_lock_date < today`.
- Locked sessions are excluded from `getActivePlayers` (W/L stats) and `getSeasonMatchCount`.
- The lock date check uses Pacific time to match the rest of the app's date logic.
