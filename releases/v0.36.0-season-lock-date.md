# Release v0.36.0 — Season Lock Date

**Date:** 2026-05-12

## Summary
Rearchitects stats lock from per-session to per-season. One date on the season excludes all sessions after it from the leaderboard.

## DB Migration
`supabase/migrations/20260512_season_stats_lock_date.sql` — adds `stats_lock_date DATE NULL` to `seasons` table.

## Files Changed

| File | Change |
|------|--------|
| `supabase/migrations/20260512_season_stats_lock_date.sql` | Create — DDL |
| `src/lib/db/seasons.ts` | `Season` + `SeasonWithStats` get `stats_lock_date`; `SeasonSession`/`sessions` field removed; `getAllSeasons` drops per-session lock query; `getActiveSeason` selects lock date |
| `src/app/api/seasons/[id]/route.ts` | PATCH accepts `stats_lock_date` |
| `src/lib/db/players.ts` | `getActivePlayers` accepts `seasonLockDate`; locked session fetch now `session.date > lockDate` |
| `src/lib/db/matches.ts` | `getSeasonMatchCount` accepts `seasonLockDate`; filter changed to `sessions.date <= lockDate` |
| `src/app/(app)/leaderboard/page.tsx` | Passes `seasonLockDate` to both functions; locked count query uses `session.date > lockDate` |
| `src/app/(app)/page.tsx` | Passes `seasonLockDate` to `SessionListClient` |
| `src/app/(app)/SessionListClient.tsx` | Accepts `seasonLockDate`; 🔒 badge when `session.date > seasonLockDate` |
| `src/components/SeasonCard.tsx` | Lock date in edit form; lock shown in collapsed view; sessions list removed entirely |
