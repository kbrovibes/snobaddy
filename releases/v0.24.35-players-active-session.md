# v0.24.35 — Players tab: fix check-in for reopened sessions

## Bug fixed
Players tab showed no check-in controls when an admin reopened a session whose date didn't match today (e.g. Monday's session reopened on Thursday).

**Root cause**: `players/page.tsx` called `getTodaySession()` which queries `WHERE date = today`. A session from a different date with `status = 'active'` was invisible to it.

**Fix**: Replaced `getTodaySession()` with `getActiveSession()` which queries `WHERE status = 'active'`. The presence query and all props now derive from `activeSession` directly, removing the redundant `status === "active"` guard that was already implied.

## Feature added
Green session banner added to the Players tab when a session is active, showing the session date formatted as "Monday, April 14 · active". Hidden when no session is active.
