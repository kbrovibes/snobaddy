# Release v0.15.0 — UI Tweaks (Spec 13)

## Summary

Three small UI improvements across different pages.

## Files changed

| File | Change |
|------|--------|
| `src/app/(app)/leaderboard/LeaderboardTable.tsx` | Removed `skill_level` from `SortKey` type, `COLUMNS` array, and row cell |
| `src/app/(app)/session/[id]/page.tsx` | Added match count to "Tonight's Scores" section header |
| `src/lib/db/matches.ts` | Added `getPlayerMatchesBySession` and `PlayerMatchBySession` interface |
| `src/app/(app)/players/[id]/page.tsx` | Replaced flat paginated match list with session-grouped rendering; removed pagination |

## Notes

- `getPlayerMatchesBySession` fetches all matches for a player in a single query (no pagination), ordered ascending within each session so matches display chronologically. Sessions are returned sorted most-recent-first.
- Pagination was removed from the player detail match history section. The `getPlayerMatches` function remains in `matches.ts` for any future use.
- The `total` count on the match history header now sums across all session groups instead of using the DB count.
