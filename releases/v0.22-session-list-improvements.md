# v0.22.4–0.22.7 — Session List Improvements

Consolidates several session list fixes and UX tweaks shipped on 2026-04-06.

## v0.22.4 — Past-dated pending sessions now visible
**Problem:** Sessions that were never started (status=`pending`) but whose date had passed were invisible — excluded from both Upcoming (date filter) and Past Sessions (status filter).
**Fix:** Anything with `status = 'pending'` and `date < today` now appears in Past Sessions.

## v0.22.5 — Test Sessions in their own section
Test sessions now appear in a dedicated "Test Sessions" section at the bottom of the list, separated from real Past Sessions. Previously they were mixed in with Past Sessions when the toggle was on.

## v0.22.6 — Control Panel entry point moved to Admin Panel
Removed the "⚙ Panel" header button. God Mode users now access the Control Panel via a purple card at the top of the Admin Panel page.

## v0.22.7 — Test Sessions toggle restored
The Test Sessions section header has an inline on/off toggle (default off, saved to `localStorage`). The list of test sessions collapses when toggled off.
