# v0.21.0 — Test Sessions

## Summary
Adds an `is_test_session` flag to sessions, auto-set based on day of week, with admin overrides and per-device visibility toggles on the session list and leaderboard.

## DB Migration
`supabase/migrations/20260405_test_sessions.sql`
```sql
ALTER TABLE sessions
  ADD COLUMN is_test_session boolean NOT NULL DEFAULT false;
```
Run this in the Supabase SQL editor before deploying.

## Files Changed

| File | Change |
|---|---|
| `supabase/migrations/20260405_test_sessions.sql` | New — adds `is_test_session` column |

## Key Design Decisions
- **Auto-detection**: day of week in America/Los_Angeles; not Mon/Thu → `is_test_session = true`
- **Filter persistence**: `localStorage` only — per-device, never touches DB
- **Leaderboard**: both datasets fetched server-side at page load; client toggles between them with no extra round-trip
- **Non-admins**: test sessions always excluded from list history and leaderboard; no toggle shown
