# v0.24.1 — Session Controls UX

## Summary
Button color fixes and reset button improvements for session management.

## Files changed
| File | Change |
|------|--------|
| `src/components/CloseSessionButton.tsx` | Red → teal/green colors throughout |
| `src/components/ResetSessionButton.tsx` | Show tally count in confirmation dialog |
| `src/app/api/sessions/[id]/reset/route.ts` | GET counts + POST deletes `session_tally` rows |
| `src/app/(app)/session/[id]/page.tsx` | Reset button shown for completed sessions (god mode); Close above Reset in active sessions |

## Details

### CloseSessionButton
- All red classes replaced with teal equivalents: `bg-teal-50`, `border-teal-200`, `text-teal-700`, confirm button `bg-teal-600`

### ResetSessionButton
- `counts` type extended to include `tally: number`
- Dialog shows tally entry count when `> 0`

### Reset API
- GET: parallel-fetches `session_tally` count alongside matches and proposed
- POST: parallel-deletes `session_tally` rows alongside matches and proposed

### Session page
- Active sessions: Close button rendered above Reset button (positive before destructive)
- Completed sessions: `{isGodMode && <ResetSessionButton />}` added after the "session closed" banner + reopen button
