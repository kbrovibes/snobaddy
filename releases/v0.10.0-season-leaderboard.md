# Release v0.10.0 — season-leaderboard

## Technical Detail
- **Leaderboard Stats Aggregation** — Updated `getAllPlayers` in `src/lib/db/players.ts` to fetch all matches and aggregate wins, losses, and matches played in-memory. This provides real-time stats across all sessions.
- **Season Match Count** — Added `getSeasonMatchCount` to `src/lib/db/matches.ts` to show the total number of games played this season.
- **Leaderboard UI** — Updated `/leaderboard` to filter for active players (1+ matches), add a Skill level column, and highlight the top 3 players with gold/silver/bronze backgrounds and medals.
- **Performance** — Aggregation is performed in-memory on the server, which is efficient for the current scale (~50 players, ~500 matches).

## Files Changed
- `src/lib/db/players.ts` — Updated `getAllPlayers` with match aggregation.
- `src/lib/db/matches.ts` — Added `getSeasonMatchCount` and fixed a minor syntax error in `getSessionScoreboard`.
- `src/app/(app)/leaderboard/page.tsx` — Added total match count display and active player filtering.
- `src/app/(app)/leaderboard/LeaderboardTable.tsx` — Added Skill column and top-3 highlighting.

## DB Changes
- None (uses existing `players` and `matches` tables).

## Migration notes
- No migration required. Stats are computed from existing data.
