# v0.7.0 — Admin Match Controls

## What changed

Admins can now edit or delete matches recorded during an active session, directly from the match history on the session tab.

## New files

- `src/app/api/matches/[id]/route.ts` — `DELETE` and `PATCH` handlers
- `src/components/MatchAdminControls.tsx` — inline edit/delete UI per match row

## Modified files

- `src/app/(app)/page.tsx` — renders `MatchAdminControls` below each match when `isAdmin && isActive`

## API

### `DELETE /api/matches/[id]`
- Admin only (403 otherwise)
- Returns 409 if the session is not `active`
- Deletes the match row

### `PATCH /api/matches/[id]`
- Admin only (403 otherwise)
- Returns 409 if the session is not `active`
- Body: `{ team1_score: number, team2_score: number }`
- Validates scores are non-negative and not tied
- Recalculates and persists `winning_team`

## Guard logic

Both API routes join `matches` → `sessions` and check `sessions.status === 'active'` before writing. The UI also gates the controls on `isActive`, but the API check is the authoritative lock.

Completed sessions require re-open (already implemented in v0.6) to unlock editing.
