## Behaviour notes

- `/` checks `getActiveSession()` first — if active, does a server-side `redirect()` before rendering the list.
- `/api/sessions/create` enforces the no-duplicate-active rule: if a session on a different date is already active, returns 400.
- `StartTodayButton` and `/api/sessions/start-today` are **not deleted** — tracked in backlog for cleanup.
- Session list shows all sessions ordered most-recent-first. Season header uses the most recent session's season name.
- Next.js 16 async params pattern used: `params: Promise<{ id: string }>` + `await params`.
