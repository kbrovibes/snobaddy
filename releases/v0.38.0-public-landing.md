# v0.38.0 — Public Landing & Explore Pages

## Summary
Added a public-facing landing page and explore page so unauthenticated users can see what the club is about before signing up.

## Changes

### Public route group `(public)/`
- **`src/app/(public)/layout.tsx`** — minimal layout wrapper, no auth required
- **`src/app/(public)/welcome/page.tsx`** — hero landing page with:
  - App branding + serve icon
  - "See what's happening" button → `/explore`
  - "Join the club" button → `/login`
  - Info cards (Mon & Thu, 2 Courts, 30-50 players)
  - If already authenticated, redirects to `/` (session list)
- **`src/app/(public)/explore/page.tsx`** — public data page with:
  - Active season name and date range
  - Stats cards (players, matches, days of play)
  - "Happening Now" callout for active sessions
  - Upcoming sessions list (next 4)
  - Recent completed sessions (last 5)
  - "Join the club" CTA at bottom
  - Uses service role client to bypass RLS (no auth needed)

### Auth flow change
- **`src/app/(app)/layout.tsx`** — unauthenticated users redirect to `/welcome` instead of `/login`

## Migration
No DB changes required.
