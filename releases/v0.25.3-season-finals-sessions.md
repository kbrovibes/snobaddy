# v0.25.3 — Season Finals: Session Generation

**Date:** 2026-04-11
**Type:** Feature (God Mode only)

## What's new

Task 5 of the Season Finals feature. Sessions tab is now functional.

### Session generation
- `POST /api/finals/[id]/generate-sessions` — creates two `session_type='finals'` sessions (one per day), links them to the finals event via `finals_event_id`, stores their IDs in `finals1_session_id` / `finals2_session_id`, and advances the event status to `sessions_created`.
- Body: `{ day1_date: "YYYY-MM-DD", day2_date: "YYYY-MM-DD" }`
- Idempotent guard: returns 409 if sessions already exist.

### Sessions tab UI
- Date pickers for Day 1 (Groups A & B) and Day 2 (Group C)
- "Generate Finals Sessions" button (disabled until both dates selected)
- After generation: session cards with status badge and direct link to the session page

### Finals session page
- Shows "🏆 Season Finals" header instead of season name
- "← Finals Event" back link instead of "← Sessions"
- Check-in button, Who's Here, and tally entry are hidden (not applicable to Finals)
- Pending state shows a "Season Finals — this session hasn't started yet" banner for non-admins
- Start/Close/Reopen buttons still work normally via existing session lifecycle

### Checkin route guard
- `POST /api/sessions/[id]/checkin` now returns 400 for `session_type='finals'` sessions
