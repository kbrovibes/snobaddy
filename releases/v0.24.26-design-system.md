# v0.24.26 — Design System + Players Screen Redesign

## Summary
Global design system overhaul (font, color palette, button style) + complete Players/check-in screen redesign.

## Files changed

| File | Change |
|---|---|
| `src/app/globals.css` | Background `#FAFAF9`, foreground `#1C1917`, `--font-jakarta` variable |
| `src/app/layout.tsx` | Switched from Geist Sans to Plus Jakarta Sans via `next/font/google` |
| `src/components/PlayerCheckinCard.tsx` | Complete rewrite — tappable card, corner ribbon, colored avatar, status line |
| `src/components/AdminPageContent.tsx` | New header with pills + Add button; 2-column grid |
| All `src/**/*.tsx` | `gray-*` → `stone-*` color migration (sed mass replace) |
| Primary buttons | `bg-sky-600 text-white` → `bg-stone-900 text-white` on all CTA buttons |

## Design tokens applied
- **Font**: Plus Jakarta Sans (400–800 weights)
- **Background**: `#FAFAF9` (stone-50)
- **Text primary**: `#1C1917` (stone-900)
- **Text muted**: `#78716C` (stone-500)
- **Border default**: `#E7E5E4` (stone-200)
- **Border present**: `#34D399` (emerald-400)
- **Button primary**: `#1C1917` bg, white text, 10px radius
- **Card radius**: 12px
- **Avatar radius**: 8px, 30×30px, color keyed to player name first char

## Check-in card behavior
- Whole card is the tap target (no sub-button)
- Absent → check in; Present → check out
- Corner triangle ribbon in `#34D399` with ✓ when present
- Box shadow `0 2px 8px rgba(52,211,153,0.18)` when present
- Avatar color cycles through 8 colors based on `name.charCodeAt(0) % 8`

## Not changed
- Sky accent colors for text links, nav active state, "In Progress" badge, toggle switches
- `nextjs-toploader` color (sky-500)
- Red admin avatar in Header
