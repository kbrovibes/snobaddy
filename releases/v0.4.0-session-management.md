# v0.4.0 — Session Management

**Released:** 2026-03-30
**Type:** Feature

## What changed

The home tab now shows tonight's session. Sessions are pre-created for every Monday and Thursday in the season. Only admins can activate a session; players see a "starting soon" state until then. Players check themselves in once the session is active.

## Technical detail

### Database tables created
- `seasons` — `name`, `start_date`, `end_date`
- `sessions` — linked to season, `date`, `status` (pending/active/completed)
- `session_players` — check-in records: `session_id`, `player_id`, `checked_in_at`

### Seed data
Spring 2026 season seeded with 18 sessions (all Mondays and Thursdays from Mar 23 – May 21, 2026), all starting as `pending`.

### Home page states
| State | Who sees what |
|-------|--------------|
| Not a session day | "No session today" + next session date |
| Session pending, admin | Green "▶ Start Tonight's Session" button |
| Session pending, non-admin | "Starting soon" message |
| Session active | Check-in button, who's here list, scoreboard, record match button |

### Session activation
`POST /api/sessions/[id]/start` — admin-only, sets status → `active`, records `started_by` + `started_at`

### Check-in
`POST /api/sessions/[id]/checkin` — requires active session; admin can pass `player_id` in body to check in others; self-check-in if no body

### Logo
`serve-logo.jpg` added to `public/` and displayed in the session header.
