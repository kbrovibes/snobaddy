# v0.21.4 — God Mode Control Panel

## What shipped
New admin-only page at `/admin/control-panel`, visible only to players with `is_god_mode = true`.

## Files changed
| File | Action |
|------|--------|
| `src/app/(app)/admin/control-panel/page.tsx` | Created |
| `CHANGELOG.md` | Updated |

## Details
- Guarded by `is_god_mode` check on the `players` row; non-god-mode users are redirected to `/`.
- **Supabase section**: calls `api.supabase.com/v1/projects/{ref}/database/query` (using `SUPABASE_MGMT_TOKEN` + `SUPABASE_PROJECT_ID`) to fetch DB size, per-table row counts, and auth user count.
  - DB size shown as `X / 500 MB` with a colour-coded progress bar (green → yellow → red at ≥80%).
  - App tables listed: `players`, `sessions`, `matches`, `session_players`, `proposed_matches`, `seasons`, `session_tally`.
- **Vercel section**: calls `api.vercel.com` (using `VERCEL_API_TOKEN`) for account plan and last 5 deployments with status badges.
  - Deployment list is conditional on `VERCEL_PROJECT_ID` being set; shows a hint if it's missing.
  - Entire Vercel card is suppressed if `VERCEL_API_TOKEN` is not set.
- All four env vars (`SUPABASE_MGMT_TOKEN`, `SUPABASE_PROJECT_ID`, `VERCEL_API_TOKEN`, `VERCEL_PROJECT_ID`) must be added to the Vercel project dashboard for production.

## Env vars required (Vercel dashboard)
- `SUPABASE_MGMT_TOKEN` — Supabase Management API token (Personal Access Token)
- `SUPABASE_PROJECT_ID` — Supabase project reference (e.g. `zwwkcwdqsplztlmyfpyf`)
- `VERCEL_API_TOKEN` — Vercel personal access token
- `VERCEL_PROJECT_ID` — Vercel project ID (from Project Settings → General)
