# Release v0.9.1 — Match History Alignment

## Overview
This patch fix addresses a layout inconsistency in the session match history view where the "vs" separator was vertically misaligned due to varying player name lengths.

## Changes

### 1. Match History Grid Layout
- **Component:** `src/app/(app)/page.tsx`
- **Before:** A `flex` container with `gap-2`. Because Team 1 names vary in length (e.g., "Alice & Bob" vs "Christopher & Alexander"), the "vs" text would shift horizontally.
- **After:** A `grid` layout with `grid-cols-[1fr_auto_1fr]`.
    - **Team 1:** Right-aligned, flex-1 equivalent.
    - **Separator:** Fixed width/centered "vs".
    - **Team 2:** Left-aligned, flex-1 equivalent.
- Added `truncate` to team name spans to ensure long names don't break the layout on small screens.

## Technical Notes
- Used Tailwind's `truncate` utility to handle overflow gracefully.
- The `grid-cols-[1fr_auto_1fr]` ensures the center column stays fixed while the two sides distribute remaining space equally.
