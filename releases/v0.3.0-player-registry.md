# v0.3.0 — Player Registry

**Released:** 2026-03-30
**Type:** Feature

## What changed

A `/players` page listing all registered players with their skill level and season stats. Admins can edit any player's skill level directly from this page.

## Technical detail

### Players page (`/players`)
- Server component fetches all players with `onboarding_complete = true`, sorted alphabetically
- Skill level shown as filled dots (●●●○○) for all users
- Admins see interactive `SkillEditor` component instead — tapping a dot updates the skill level via `PATCH /api/players/[id]`
- W / L / matches columns present but show 0 until matches are recorded (populated in v0.6.0)

### API
- `GET /api/players` — all onboarded players
- `PATCH /api/players/[id]` — admin-only, updates `skill_level` (validates 1–5, checks `is_admin` server-side)

### Manually-added players
`user_id` column made nullable so admins can add players who don't have Google accounts (walk-in players, test players, etc.)
