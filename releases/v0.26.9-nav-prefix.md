# v0.26.9 — Nav link prefix consistency

## Summary
Changed finals-related back-navigation links to use the `‹` character instead of `<`, matching the convention used everywhere else in the app.

## Files changed
| File | Change |
|------|--------|
| `src/app/(app)/finals/[id]/page.tsx` | `{"<"} Sessions` → `‹ Sessions` |
| `src/app/(app)/session/[id]/page.tsx` | `{"<"} Finals Event` → `‹ Finals Event` |
