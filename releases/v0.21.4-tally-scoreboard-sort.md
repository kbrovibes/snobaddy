# v0.21.4 — Tally Scoreboard: sortable columns + match count + profile links

## Summary
`TallyScoreboard` converted from a static server component to an interactive client component with sortable columns, a match count column, and player name links.

## Files changed
| File | Change |
|------|--------|
| `src/components/TallyScoreboard.tsx` | Rewritten as `"use client"` — sortable columns, M column, profile links |
| `CHANGELOG.md` | v0.21.4 entry |

## Details
- Follows the same `COLUMNS` array + `useState(sortKey, sortDir)` pattern as `SessionScoreboard`
- Default sort: `wins` descending (previously hard-coded, now user-togglable)
- New `M` column: `wins + losses` (total matches played)
- Player names render as `<Link href="/players/{player_id}">` — same destination as leaderboard profile links
- Sort tiebreaker: total matches (desc), then name (asc)
