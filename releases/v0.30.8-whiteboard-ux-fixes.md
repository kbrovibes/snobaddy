# v0.30.8 — Whiteboard UX Fixes

**Date:** 2026-04-27

## Changes

### Dark mode: checked-out player visibility
- `src/components/WhiteboardTally.tsx` — Changed `text-black` to `text-stone-400 dark:text-stone-500` for checked-out player names, W counts, and L counts. Added dark variants to tap-flash row backgrounds.

### Activity "Show more"
- `src/components/ActivityShowMore.tsx` — New client component. Shows first 10 feed items with a "Show N more..." expand button.
- `src/app/(app)/session/[id]/page.tsx` — Wrapped activity feed items in `ActivityShowMore`.

### Undo → table sync
- `src/components/WhiteboardTally.tsx` — Added `useEffect` to sync local `tallies` state when `players` prop changes after `router.refresh()`.

### Inline score editing
- `src/components/WhiteboardTally.tsx` — Added pencil (✎) button next to +W/+L. Opens −/+ steppers for W and L with a "done" dismiss. Added `handleDecrement` function using existing `delta: -1` API support. Widened action column from 4.5rem to 6rem.

### Display name disambiguation
- `src/app/(app)/session/[id]/page.tsx` — Added whiteboard player names and log entry names to nameMap source. Passed `nameMap` to `WhiteboardTally`. Changed activity log to use `shortName()` instead of raw `.split(" ")[0]`.
- `src/components/WhiteboardTally.tsx` — Accepts optional `nameMap` prop. Renamed `firstName()` to `displayName()` which consults nameMap first.
