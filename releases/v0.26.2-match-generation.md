# v0.26.2 — Fixed-Partner Match Generation

## What
Round-robin match generation and display for Fixed-Partner format.

## Changes
- `src/app/api/sessions/[id]/finals-format/generate-matches/route.ts` — POST endpoint generates all pair-vs-pair matches at once. Distributes to avoid consecutive play. Sets match_type='finals_group' and finals_group='A'/'B'. Updates format status to 'matches_generated'.
- `src/components/finals/GenerateMatchesButton.tsx` — Button to trigger match generation, shown after pairs are saved.
- `src/components/finals/FinalsMatchList.tsx` — Match display with group tabs, progress bar, pair labels, inline score entry via PATCH /api/matches/[id].
- `src/lib/db/finals.ts` — Added getFinalsMatches() query helper and FinalsMatchRow type.
- `src/app/(app)/session/[id]/page.tsx` — Integrated all new components. Fetches finals matches when format status is matches_generated or completed.

## Data
Matches stored in existing `matches` table with `match_type='finals_group'` and `finals_group` set. Scores recorded via existing PATCH endpoint. No new DB migration needed.
