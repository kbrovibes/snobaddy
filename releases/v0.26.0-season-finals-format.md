# v0.26.0 — Season Finals: Format Selection

**Date:** 2026-04-11
**Type:** Feature (God Mode only)

## What's new

Task 6 of the Season Finals feature. Format selection is now available on Finals Session pages.

### Format picker UI
- Card-based format selector on the Finals Session page (God Mode only)
- "Fixed-Partner All-Pairs" — active and selectable
- "Playoffs + Finals" — greyed out with "Coming soon" tag
- Shows group sizes (Group A / Group B player counts) from the finals breakdown
- Selection highlighted with checkmark; can be changed until matches are generated

### Database
- New `finals_formats` table — one row per finals session, stores format type, status, and config (jsonb)
- RLS enabled with authenticated access policy

### API
- `GET /api/sessions/[id]/finals-format` — fetch current format (God Mode)
- `POST /api/sessions/[id]/finals-format` — set or update format (God Mode, only while status is `configured`)

### Files changed
- `supabase/migrations/20260411_finals_formats.sql` — new migration
- `src/lib/db/finals.ts` — added `FinalsFormat` interface + `getFinalsFormat()` helper
- `src/app/api/sessions/[id]/finals-format/route.ts` — new API route
- `src/components/finals/FormatPicker.tsx` — new client component
- `src/app/(app)/session/[id]/page.tsx` — integrated format picker + data fetching
