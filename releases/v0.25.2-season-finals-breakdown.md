# v0.25.2 — Season Finals: Breakdown Generation

**Date:** 2026-04-11
**Type:** Feature (God Mode only)

## What's new

Task 4 of the Season Finals feature. The Groups tab is now fully functional.

### Breakdown generation
- `POST /api/finals/[id]/generate-breakdown` — scores all participants using Finals Score = Skill (50%) + Win Rate (50%), auto-assigns groups (top 35% → A, next 35% → B, rest → C). Idempotent: can be re-run to reset non-overridden players.
- Finals Score formula: `SkillScore = ((skill_level-1)/4)*100`, `WinRate = wins/(wins+losses)*100` (defaults to 50 if no data). `FinalsScore = SkillScore*0.5 + WinRate*0.5`.
- Preserves manual `group_override=true` rows during re-runs.

### Group override
- `PATCH /api/finals/[id]/participants/[playerId]/group` — manually move a player to A/B/C; sets `group_override=true` and updates `finals_day`. Only allowed in `breakdown_generated` state.

### Confirm breakdown
- `POST /api/finals/[id]/confirm-breakdown` — validates each group has ≥ 4 players. Returns an error if not. Status remains `breakdown_generated` until sessions are generated (Task 5).

### Groups tab UI
- Ranked table: Rank / Name / Skill dots / WR% / Finals Score / Group selector / Info toggle
- Group dividers with player count and warning if < 4 players
- Group colour coding: A = sky, B = amber, C = stone
- Expandable score explanation per player (ℹ button)
- "Override" badge on manually reassigned players
- Group size summary pills at the bottom
- "Generate Breakdown" / "Re-run Breakdown" button
- "Confirm Groups → Proceed to Sessions" button (disabled if any group < 4)
