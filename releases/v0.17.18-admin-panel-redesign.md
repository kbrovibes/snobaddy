# v0.17.18 — Admin Panel redesign

## What changed
- "Players" tab renamed to "Admin" in bottom nav
- Players page title changed to "Admin Panel"
- Player list converted from rounded card per row → flat `<table>` with `border-b` rows (matches WhoIsHere/LeaderboardTable style)
- `AdminPresenceToggle` replaced single ambiguous toggle button with two explicit buttons:
  - **"Check In"** (blue) — shown when player is absent or checked-out
  - **"Check Out"** (red) — shown when player is present
- SkillEditor retained in the table's Skill column
- When no active session, table shows W/L columns instead of presence column
