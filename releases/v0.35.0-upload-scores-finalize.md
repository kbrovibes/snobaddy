# Release v0.35.0 — Upload Scores & Finalize

**Date:** 2026-05-12

## Summary
Adds an admin-only "Upload Scores & Finalize" button to pending (unopened) sessions on the session detail page. This allows admins to finalize a session and upload tally scores without ever having to open the session for live play — useful when the session was played but never activated in the app.

## Changes

| File | Action |
|------|--------|
| `src/components/UploadScoresButton.tsx` | Create — client component with confirmation dialog, calls `/close` then refreshes |
| `src/app/(app)/session/[id]/page.tsx` | Modify — import + render `UploadScoresButton` above `StartSessionButton` for `isPending && isAdmin && !isFinalsSession` |
| `src/app/api/sessions/[id]/close/route.ts` | Modify — changed `.eq("status", "active")` to `.in("status", ["active", "pending"])` so pending sessions can be finalized |

## Flow
1. Admin visits a pending session page
2. Sees "📷 Upload Scores & Finalize" above the "Open Session" button
3. Clicks it → confirmation dialog
4. Confirms → `POST /api/sessions/{id}/close` sets status to `completed`
5. Page refreshes → session is now completed → `TallyEntryForm` appears naturally with photo upload + manual entry
6. Admin uploads whiteboard photo or enters scores manually

## Notes
- Finals sessions are excluded from this button (tally upload doesn't apply to finals)
- The auto-checkout step in the close route is a no-op for pending sessions (no check-in rows exist)
- Pre-existing `web-push` build error is unrelated to this change
