# v0.27.0 — Drag-and-drop group assignment

## Summary
Added drag-and-drop support for moving players between groups in the Finals setup wizard. Also fixed nav link consistency and hid unnecessary prev/next session nav on finals sessions.

## Dependencies added
- `@dnd-kit/core`
- `@dnd-kit/sortable`
- `@dnd-kit/utilities`

## Files changed
| File | Change |
|------|--------|
| `src/app/(app)/finals/[id]/FinalsEventTabs.tsx` | Replaced single ranked table with per-group droppable containers. Added `DragHandle`, `DraggablePlayerRow`, `DroppableGroup`, `DragOverlayRow`, and `GroupsDragDrop` components. |
| `src/app/(app)/session/[id]/page.tsx` | Hide prev/next session nav for finals sessions; fixed ‹ prefix |
| `src/app/(app)/finals/[id]/page.tsx` | Fixed ‹ prefix (committed in prior push) |
| `package.json` | Added @dnd-kit dependencies |

## Notes
- Drag handle uses a 6-dot grip icon (⠿ pattern), standard mobile convention
- Touch activation uses 200ms delay to avoid conflict with scrolling
- Groups render as separate cards with blue ring highlight on drag-over
- Read-only mode (confirmed groups) hides drag handles entirely
