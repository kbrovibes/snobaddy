# Release v0.35.1 — Session Lock Date UX

**Date:** 2026-05-12

## Summary
Simplified the session lock date UI in the Seasons admin page to an always-visible inline date picker (auto-saves on change). Added a subtle 🔒 badge to locked sessions in the session list page.

## Changes

| File | Action |
|------|--------|
| `src/components/SeasonCard.tsx` | Modify — replaced `SessionLockRow` edit-toggle pattern with inline `<input type="date">` that auto-saves on change; removed Save/Clear/Cancel buttons and `editing` state |
| `src/app/(app)/SessionListClient.tsx` | Modify — added `🔒` badge (amber, with tooltip) on session rows where `stats_lock_date` is in the past |

## Notes
- Leaderboard already shows "N sessions excluded · stats locked" count at the bottom — no change needed there
- Auto-save fires on `onChange` of the date input (fires when user picks a date from the picker, not on every keystroke)
- Clearing the date input sends `null` to the API, removing the lock
