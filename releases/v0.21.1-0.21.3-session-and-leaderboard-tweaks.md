# v0.21.1–0.21.3 — Session List & Leaderboard Tweaks

Shipped 2026-04-05/06 as part of the Test Sessions (Spec 22) follow-up work.

## v0.21.1 — Leaderboard test-session toggle above award cards
**Change:** Moved the "Include Test Sessions" admin toggle to the top of the leaderboard page, above the award cards. Toggling it now flips the entire view: award winners, player count, table, and match total all update together.

**Files:** `src/app/(app)/leaderboard/LeaderboardTable.tsx`, `src/app/(app)/leaderboard/page.tsx`

## v0.21.2 — Session list split into Upcoming / Past sections
**Change:** The home page session list is now split into two labelled sections:
- **Upcoming** — next pending future session only, with "Opens at 6pm" subtitle and "Upcoming" badge
- **Past Sessions** — all completed and closed sessions, ordered newest first

**Fix included:** `getAllSessions()` had a broken date-cutoff that caused sessions on or after today to disappear when a same-day session was created. Fixed by removing the cutoff entirely; sections are computed client-side.

**Files:** `src/app/(app)/SessionListClient.tsx` (created), `src/app/(app)/page.tsx`, `src/lib/db/sessions.ts`

## v0.21.3 — Upcoming shows only the single next session
**Change:** Further tightened the Upcoming section to show exactly one session — the single nearest future pending session. Previous version showed all pending sessions within 7 days.

**Files:** `src/app/(app)/SessionListClient.tsx`
