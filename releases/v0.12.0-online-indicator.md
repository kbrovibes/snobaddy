# v0.12.0 — Online indicator in Who's Here

## Summary
Small green dot next to players in the "Who's Here" list who have been active in the app within the last 8 hours.

## Approach
Uses the Supabase Admin Auth API (`auth.admin.listUsers`) via the service role client to check each checked-in player's `last_sign_in_at`. Players without a linked `user_id` (manually added) never show the dot.

## Files changed
| File | Change |
|---|---|
| `src/lib/db/players.ts` | Added `getOnlinePlayerIds(playerIds)` — returns a `Set<string>` of player IDs active in the last 8 hours |
| `src/app/(app)/page.tsx` | Call `getOnlinePlayerIds` in the existing parallel fetch; pass result to `WhoIsHere` |
| `src/components/WhoIsHere.tsx` | Accept `onlinePlayerIds?: Set<string>` prop; render a `w-2 h-2 bg-green-500 rounded-full` dot before the player name when present |

## Notes
- 8-hour window is intentionally loose — covers anyone who opened the app before or during the evening session
- No schema changes required
