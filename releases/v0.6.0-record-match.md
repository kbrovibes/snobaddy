# v0.6.0 — Record a Match & Live Scoreboard

**Released:** 2026-03-30
**Type:** Feature

## What changed

Anyone can record a completed doubles match from the session tab. The live scoreboard updates immediately showing W/L/Win% for all checked-in players. Match history for the night is shown below.

## Technical detail

### Database
`matches` table:
- `session_id`, `team1_player1_id`, `team1_player2_id`, `team2_player1_id`, `team2_player2_id`
- `team1_score int`, `team2_score int`
- `winning_team int check (winning_team in (1, 2))` — derived from scores at write time

### RecordMatchForm (full-screen mobile form)
- Triggered by "🎾 Record a Match" button on the session page
- Full-screen overlay with Cancel / Save header (native mobile pattern)
- 4 player selectors — each dropdown excludes already-selected players (cross-filtered)
- Empty state shown in grey, selected player shown in dark text with blue border
- Score inputs: large number fields side by side, live "🏆 Team X wins" preview as you type
- Validation: 4 unique players, no ties, all players must be currently checked in

### API: `POST /api/matches`
Server-side validations:
1. All 4 player IDs are unique
2. Scores are not equal
3. All 4 players have a `session_players` row with `checked_out_at IS NULL` for this session
Derives `winning_team` from scores and stores it.

### Live scoreboard
`getSessionScoreboard(sessionId)` aggregates match results for the session:
- Counts wins/losses per player from the `matches` table
- Returns all currently checked-in players (even those with 0 matches)
- Sorted by win%, tiebroken by matches played
- Your own name highlighted in blue

### Match history
Most recent matches shown newest-first below the scoreboard. Winner's team name in green, loser in grey, score displayed.
