# v0.19.0 — Player Poems

## What changed

AI-generated funny 2–3 line poems per player, shown on the player profile page below their name.

## Files changed

| File | Action |

| `supabase/migrations/20260404_player_poems.sql` | Create — new `player_poems` table |

## DB migration

Run in Supabase SQL editor:

```sql
create table if not exists player_poems (
  player_id uuid primary key references players(id) on delete cascade,
  poem text not null,
  matches_at_generation int not null default 0,
  created_at timestamptz not null default now()
);
```

## Environment variables

`ANTHROPIC_API_KEY` must be set in `.env.local` and Vercel dashboard.

## Behaviour

- On first visit to a player's profile, a poem is generated and cached.
- Poems regenerate when the player's total match count changes by ≥ 3.
- If generation fails (no API key, network error, etc.), the poem is silently skipped — the page still loads normally.
