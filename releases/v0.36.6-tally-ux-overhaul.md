# v0.36.6 — Tally Entry UX Overhaul + Name Alias Learning

**Date:** 2026-05-12

## Summary

Redesigned the tally entry form buttons, player picker, and added persistent name alias learning for photo-based score extraction.

## Changes

### 1. Buttons (TallyEntryForm closed state)
- "Enter Final Scores" dashed button → "Enter Scoreboard Manually" full-width solid button (stone-900/sky-600)
- Camera emoji icon button + model label → "Upload Scoreboard Photo" full-width solid purple button
- Removed `MODEL_LABELS` map and `modelLabel()` helper, removed `tallyModel` prop

### 2. Player selection (TallyEntryForm open state)
- Replaced single `<select>` dropdown with a toggleable checkbox multi-select picker
- Shows all players with checkboxes; checked = already in the score list
- Toggling a checkbox adds/removes the player row instantly

### 3. Name corrections banner
- After photo extraction, shows a purple banner listing all name corrections applied (e.g. "Tredeb" → "Tridib Basu")
- Corrections from persisted aliases are also shown

### 4. Name alias persistence (extract + tally save APIs)
- New `tally_name_aliases` key in `app_settings` stores a JSON map of `raw_name → player_name`
- **Extract API** (`/api/sessions/[id]/tally/extract`): loads aliases before name matching; aliases are checked after exact match but before first-name/partial matching
- **Tally save API** (`/api/sessions/[id]/tally`): after saving, compares raw AI extraction names against saved player IDs to learn new aliases automatically

## Files changed

| File | Change |
|------|--------|
| `src/components/TallyEntryForm.tsx` | Complete rewrite of closed/open states; checkbox picker; name corrections banner; removed model label |
| `src/app/api/sessions/[id]/tally/extract/route.ts` | Added `loadNameAliases()`/`saveNameAliases()`, alias lookup in `matchName()`, `corrected_from_alias` flag |
| `src/app/api/sessions/[id]/tally/route.ts` | Added alias learning on save: compares raw extraction vs saved entries |
| `src/app/(app)/session/[id]/page.tsx` | Removed `tallyModel` prop and `getAppSetting` import |
