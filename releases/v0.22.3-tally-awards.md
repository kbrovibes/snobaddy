# v0.22.3 — Tally Session Awards

## What shipped
Closed tally-mode sessions now show Session Award cards, matching the layout already used on match-based sessions.

## Cards shown
| Card | Criteria |
|------|----------|
| ⚔️ The Slayer | Player(s) with most wins |
| 🚀 The Unstoppable | Player(s) with most total matches (W+L) |
| 🧊 The Untouchable | Best win rate (minimum 3 matches played) |

The Point Collector (🎯) and No Mercy (⚡) cards are intentionally skipped — tally mode doesn't record per-match point data.

## Files changed
| File | Action |
|------|--------|
| `src/components/SessionHighlights.tsx` | `AwardCard` exported so tally can reuse it |
| `src/components/TallyHighlights.tsx` | Created — computes and renders 3 tally award cards |
| `src/app/(app)/session/[id]/page.tsx` | Renders `<TallyHighlights>` above tally scoreboard; fixes `nameMap` to include tally player names (was built from scoreboard only, which is empty for tally sessions) |

## Notes
- Minimum threshold for the Untouchable card is 3 matches (same as match-based sessions)
- If no player has ≥3 matches the Untouchable card is omitted
- Grid layout adapts: 2 cards → 3+3 cols, 3 cards → 2+2+2 cols (same logic as `SessionHighlights`)
