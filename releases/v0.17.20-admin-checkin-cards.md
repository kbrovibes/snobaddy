# v0.17.20 — Admin Panel: player check-in card grid

## What changed
Replaced the flat table in the Admin Panel with a 3-column card grid.

Each card has three rows:
1. **Name** — with admin ★ and verified ✓ indicators
2. **Skill** — editable dots (SkillEditor, same as before)
3. **Action** — "Check In" or "Check Out" button when session active; W/L stats otherwise

Visual states:
- **Present**: `bg-green-50 border-green-200`, green ✓ badge (absolute, top-right)
- **Absent / checked-out**: plain `bg-white border-gray-100`
- "Check In" button: solid `bg-blue-500 text-white`
- "Check Out" button: outline `border-red-200 text-red-500`
