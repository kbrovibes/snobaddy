# v0.10.4 — Match Generation: No Repeated Matchups

## Problem
With the v0.10.2 wave fix in place, generating 4 matches with ~12 players still produced 2 duplicated matchups (same 4 players, same teams). Only 8 of 12 players were actually used.

## Root Causes

1. **Wave reset was too aggressive** — `waveLocked.clear()` at the start of wave 2 made all 12 players available with no preference for unused players. `findBestMatch` picked the same well-balanced groups from wave 1 again.

2. **Newly proposed matches not in history** — `workingHistory` was only the completed matches from DB. The just-proposed match 1 and match 2 were invisible to the scorer when evaluating match 3 and 4. The -200 exact-duplicate penalty never fired.

3. **Duplicate penalty was far too weak** — even if it had fired, -200 vs a base score of 1000 would not have deterred repeating a perfectly balanced match.

## Fixes (`src/lib/db/proposed.ts`)

### Fresh-player preference in wave 2
Introduced `wave1Players` set. At the start of wave 2:
- Compute `fresh = players not in waveLocked AND not in wave1Players`
- If `fresh.length >= 4`, pass only fresh players to `findBestMatch`
- Otherwise fall back to all unlocked players (forces different pairings via penalty)

### Working history accumulation
`workingHistory` starts as a copy of completed match history. After each proposal is generated, it is appended to `workingHistory`. All subsequent `findBestMatch` calls see the full picture, including intra-batch proposals.

### Penalty overhaul in `scoreMatch`
| Condition | Old penalty | New penalty |
|-----------|-------------|-------------|
| Exact same 4-player group | -200 | -5000 |
| 3-player overlap | -50 | -500 |
| Same team pairing (same 2 players on same side) | none | -150 |

## Behaviour with 12 players, 0 existing proposals
| Slot | Wave | Available pool | Result |
|------|------|----------------|--------|
| 0 | 1 | 12 | Match A (players 1-4), wave1Players = {1-4} |
| 1 | 1 | 8 | Match B (players 5-8), wave1Players = {1-8} |
| 2 | 2 | 4 fresh (9-12) | Match C (players 9-12) |
| 3 | 2 | 8 (1-8, fresh exhausted) | Match D — best 4 from wave 1 pool, different pairing |
