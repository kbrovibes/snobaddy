# Release v0.9.3 — First Names Only & Data Correction

## Overview
This release focuses on improving the mobile experience by using first names only in the match and score lists, and a one-time database correction for a player name.

## Changes

### 1. Show First Names Only
- **Component:** `src/app/(app)/page.tsx`
- **Logic:** Added a `getFirstName` helper function that extracts the first word of a name string.
- **Affected UI:**
    - **Who's Here List:** Now shows "Alice" instead of "Alice Smith".
    - **Scoreboard:** Player names are now shown as first names, keeping the layout compact on mobile.
    - **Match History:** Team names and "Who won" text now use first names.
- **Technical Detail:** Full names are still retrieved from the database and used for matching player IDs, but only the transformed string is displayed in the UI.

### 2. Player Name Correction
- **Database:** `players` table
- **Correction:** Updated name for email `chinnunchunni@gmail.com` from a legacy entry to "Vinaya Krishnan".
- **Method:** Executed via a one-time script using the Supabase service role client to bypass RLS.

## Technical Notes
- The `getFirstName` transformation is applied at the render layer to avoid modifying the source data in the database.
- Consistency was prioritized by applying this transformation across all session-related player lists.
