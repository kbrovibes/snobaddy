# v0.28.0 — Finals Completed View & Event Auto-Finalization

## Summary
1. Finalized finals sessions show a dedicated view: winner/runner-up cards, standings tables, series timelines, collapsible match history, and overall rankings.
2. When both finals sessions (Day 1 + Day 2) are closed, the parent finals event auto-completes. Reopening a session reverts the event.
3. A completed finals event shows a summary page with the same cards, plus a "View Setup Details" toggle for the admin workflow tabs.
