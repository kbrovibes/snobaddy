# v0.28.0 — Finals Completed View

## Summary
When a finals session is finalized (status = completed), the page now shows a dedicated view with winner/runner-up cards per group and an overall player rankings table. All non-finals UI (highlights, tally, scoreboard, match history) is hidden for finalized finals sessions.

## Files changed

| File | Change |
|------|--------|
| `src/components/finals/FinalsCompletedView.tsx` | Created — renders winner/runner-up cards per group and overall rankings table |
| `src/app/(app)/session/[id]/page.tsx` | Import + render `FinalsCompletedView` when finals session is completed; hide highlights and tally sections for finals |

## How it works
- **Fixed-partner groups**: Winners and runner-ups determined by pair standings (pts = pf + wins*2), same logic as `FinalsStandings`.
- **Playoffs groups**: Winners and runner-ups determined from the best-of-3 series result. Falls back to standings if no series exists.
- **Overall rankings**: All players across all groups ranked by individual points (pts desc, pf desc).
