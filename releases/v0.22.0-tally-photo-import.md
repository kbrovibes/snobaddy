# v0.22.0 — Tally Photo Import (God Mode)

## Summary
Admins with god mode can upload a whiteboard photo on any completed session with tally mode. Gemini AI extracts player names and W/L counts, pre-fills the tally entry form, and highlights unmatched names for manual resolution. Photos are stored in Supabase Storage and viewable after save.

## DB changes
```sql
-- God mode column (set for Karthik Rajan)
ALTER TABLE players ADD COLUMN IF NOT EXISTS is_god_mode BOOLEAN NOT NULL DEFAULT FALSE;
UPDATE players SET is_god_mode = TRUE WHERE name = 'Karthik Rajan';

-- Photo path on sessions
ALTER TABLE sessions ADD COLUMN IF NOT EXISTS tally_photo_path TEXT;

-- Supabase Storage bucket (private, 10MB limit, images only)
INSERT INTO storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
VALUES ('tally-photos', 'tally-photos', false, 10485760, ARRAY['image/jpeg','image/png','image/webp','image/heic'])
ON CONFLICT (id) DO NOTHING;
```

## Flow
1. Open any completed session with tally mode
2. God mode user taps 📷 (next to "Enter Final Scores") or "📷 Import from photo" inside the open form
3. File picker opens (mobile: camera)
4. Photo uploaded to `tally-photos/{session_id}.{ext}` in Supabase Storage
5. `sessions.tally_photo_path` updated
6. Image sent to `gemini-1.5-flash` with full player roster as context
7. Extracted entries pre-fill the tally form
8. Unmatched names appear in amber — admin picks correct player from dropdown
9. Save blocked until all rows resolved
10. After save, "Source photo →" link appears (god mode only) — generates signed URL on click

## Limitations
- One photo per session (re-upload replaces)
- JPEG, PNG, WEBP, HEIC only; max 10MB
- Extraction quality depends on photo clarity and Gemini's handwriting recognition
