# v0.5.0 — Check-Out

**Released:** 2026-03-30
**Type:** Feature

## What changed

Players can now check out when they're done for the night. Admins can check in or out any player from the Players tab during an active session.

## Technical detail

### Database change
`checked_out_at timestamptz` column added to `session_players`. A player is "currently present" only if `checked_out_at IS NULL`.

### Self check-out (session page)
`CheckInButton` updated: when checked in, shows "✓ You're checked in" alongside a small "Leave" button. Tapping Leave calls `POST /api/sessions/[id]/checkout` and resets to the check-in state.

### Re-check-in after checkout
If a player checked out and wants back in, the check-in route detects the existing row with `checked_out_at` set and clears it (rather than inserting a duplicate).

### Admin check-in/out from Players page
- `AdminPresenceToggle` component: per-player pill button showing current state
  - `+ Check In` (blue) — not yet here
  - `✓ Here · Leave` (green) — currently present, tap to check out
  - `Left · Re-add` (grey) — checked out, tap to re-add
- Visible only to admins when a session is active
- Passes `player_id` in the request body; API validates that caller is admin

### API
- `POST /api/sessions/[id]/checkout` — self or admin with `{ player_id }` in body
- `POST /api/sessions/[id]/checkin` — updated to support admin + re-check-in logic
