# v0.24.2 — Fix player name hidden for God Mode on profile page

## Root cause
`page.tsx` was replacing the entire name+skill area with `<EditPlayerForm>` when `isGodMode`. In its closed state, `EditPlayerForm` only rendered a ✏️ button — so the player name and skill dots disappeared entirely for God Mode users.

## Fix
- `EditPlayerForm` now always renders the name (`currentName`) and skill dots, with the ✏️ button alongside the name (visible only when `isGodMode={true}`)
- `isGodMode` prop added to `EditPlayerForm`
- `SkillDots` helper moved from `page.tsx` into `EditPlayerForm.tsx` (no longer needed in page)
- `page.tsx` now unconditionally renders `<EditPlayerForm>` (which handles the god mode guard internally)

## Files changed
| File | Change |
|------|--------|
| `src/components/EditPlayerForm.tsx` | Added `isGodMode` prop; always renders name+skill; ✏️ button conditional on `isGodMode`; added `SkillDots` helper |
| `src/app/(app)/players/[id]/page.tsx` | Removed `SkillDots`; removed god mode conditional; always renders `<EditPlayerForm isGodMode={isGodMode}>` |
