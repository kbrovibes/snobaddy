# v0.1.0 — Hello World

**Released:** 2026-03-29
**Type:** Infrastructure

## What changed

End-to-end scaffold connecting all three platforms. No app features yet — just proof that the stack works together.

## Technical detail

- Scaffolded Next.js 14 app (App Router, TypeScript, Tailwind CSS) with `create-next-app`
- Installed `@supabase/supabase-js`, configured server-side client in `src/lib/supabase.ts`
- Created `health_check` table in Supabase and seeded with one row
- Root page (`/`) is a React Server Component that queries `health_check` and renders the result
- `GET /api/health` returns `{ ok, message }` JSON from the same table
- Deployed to Vercel via GitHub auto-deploy on push to `main`
- Framework preset issue: Vercel must be set to **Next.js** (not "Other") — detected wrong on first connect because repo was empty

## Environment variables introduced
