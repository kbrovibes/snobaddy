# v0.40.1 — Dark shuttlecock glyph icons

## Summary
Replaced the crest-artwork favicon/PWA icons with a generated minimal shuttlecock
glyph on a dark navy gradient (`#1e293b` → `#0b1220`), white feathers with a sky
(`#38bdf8`) center feather and band.

## Files changed
| File | Change |
|---|---|
| `public/favicon-glyph.ico` | New — 16/32/48 PNG-in-ICO, rounded-corner background |
| `public/favicon-glyph.png` | New — 32×32 favicon |
| `public/icon-glyph-192.png` | New — PWA icon, full-bleed square |
| `public/icon-glyph-512.png` | New — PWA icon (`any` + `maskable`; glyph fits the 40%-radius safe zone) |
| `public/apple-touch-icon-glyph.png` | New — 180×180 iOS home-screen icon |

## Notes
- Icons rendered from an inline SVG via `sharp` (script not committed; lives in session scratchpad)
- Old crest assets (`favicon-crest.*`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`) left in `public/` but no longer referenced
