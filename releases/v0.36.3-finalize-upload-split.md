# v0.36.3 — Finalize & Upload Scores Split

**Date:** 2026-05-12

## Summary

Split the combined "Upload Scores & Finalize" button into two independent actions:
1. **Finalize Session** — closes the session (in-app confirmation, no more browser `confirm()`)
2. **Upload Scores** — shows the tally entry form (with photo import) on pending sessions, not just finalized ones

## Files changed

| File | Change |
|------|--------|
| `src/components/UploadScoresButton.tsx` | Renamed to "Finalize Session", replaced `confirm()`/`alert()` with in-app confirmation panel |
| `src/app/(app)/session/[id]/page.tsx` | Added `TallyEntryForm` for admins on pending sessions; expanded `formPlayers` fetch to include pending state |

## UX before → after

**Before:** Pending session showed one button "Upload Scores & Finalize" that used a browser `confirm()` dialog, finalized the session, then on page refresh showed the tally entry form.

**After:** Pending session shows two separate controls:
- "Finalize Session" button with amber in-app confirmation panel
- Tally entry form (+ Enter Final Scores / 📷 photo upload) available immediately without finalizing first
