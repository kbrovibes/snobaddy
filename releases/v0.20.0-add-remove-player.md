```sql
-- 1. Soft-delete support
ALTER TABLE players ADD COLUMN deleted_at TIMESTAMPTZ DEFAULT NULL;
CREATE INDEX players_deleted_at_idx ON players (deleted_at) WHERE deleted_at IS NULL;

-- 2. God Mode role
ALTER TABLE players ADD COLUMN is_god_mode BOOLEAN NOT NULL DEFAULT FALSE;
UPDATE players SET is_god_mode = TRUE WHERE name = 'Karthik Rajan' AND email ILIKE '%@gmail.com';
```

## Notes

- `getAllPlayers` is kept as a deprecated alias so any call sites not yet updated don't break at compile time.
- Match invalidation is implicit: any match involving a deleted player is filtered in app code. Restoring a player automatically revalidates their matches with no backfill.
- `getActivePlayers()` runs 3 parallel queries (players, matches, deleted IDs) for efficiency.
