# v0.30.12 — Season stat card accuracy fixes

## Changes
- `src/lib/db/sessions.ts` — replaced `getSeasonPlayerCount` with `getSeasonStats(sessionIds)`:
  - playerCount: unique player IDs from `matches` rows (team1/2 player columns); tally-only sessions add players from `session_tally` where wins+losses > 0
  - matchCount: exact count from `matches` rows + approximation for tally-only sessions (sum(wins)/2, since each match produces 2 wins)
- `src/app/(app)/page.tsx` — switched to `getSeasonStats`; `daysOfPlay` unchanged (getAllSessions already excludes finals and test sessions)
