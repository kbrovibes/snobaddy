# v0.26.1 — Fixed-Partner Pair Configuration

## What
Partner pairing UI for the Fixed-Partner All-Pairs format in Season Finals.

## Changes
- `src/components/finals/PairConfigurator.tsx` — New client component with per-group pair assignment dropdowns, auto-suggest by Finals Score, validation (even groups, all assigned, no duplicates)
- `src/app/api/sessions/[id]/finals-format/pairs/route.ts` — POST endpoint to save pairs into `finals_formats.config` jsonb. Validates player IDs, group membership, and format status.
- `src/app/(app)/session/[id]/page.tsx` — Integrates PairConfigurator below FormatPicker when Fixed-Partner is selected. Fetches full participant list instead of just group sizes.

## Data
Pairs stored in `finals_formats.config` as `{ pairs: { A: [{player1_id, player2_id}, ...], B: [...] } }`. No DB migration needed — uses existing jsonb column.
