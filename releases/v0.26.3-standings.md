# v0.26.3 — Fixed-Partner Standings & Winners

## What
Live pair standings and winner detection for Fixed-Partner format.

## Changes
- `src/components/finals/FinalsStandings.tsx` — Client component computing pair W/L/PF/PA from match data. Group tabs, sorted standings table, tiebreak detection (2-way suggests tiebreak match, 3+ way shows manual dropdown), winner display with trophy.
- `src/app/(app)/session/[id]/page.tsx` — Integrated FinalsStandings below FinalsMatchList.

## Logic
- Standings computed client-side from matches array (updates on page refresh after score entry)
- Sort: wins descending, then PF-PA differential descending
- Winner: first place when all matches played and no tie at top
